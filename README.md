# seal-gate

Universal standalone AI quality gate — deterministic core + optional LLM overlay.

> ⚠️ **BETA channel (`@beta` npm tag).** This is a coordinated beta
> release across the LoomKit harness family (loomkit, seal-gate,
> hammerhead-debug, pilotfish), published so `npm install
> @gotako/loomkit@beta` can pull in real dependency versions instead of
> requiring all four repos cloned side by side. **Expect crashes,
> missing pieces, and breaking changes without notice.** Not
> production-ready. Install the default (non-`@beta`) dist-tag for a
> stable version; only opt into `@beta` if you know what you're doing
> and are willing to hit rubbish.

See **[USAGE.md](./USAGE.md)** for the full API (TypeScript, Python,
CLI, Qwen Code hooks) and the complete rule table.

Part of the LoomKit harness family — see
[loomkit/HARNESS.md](https://github.com/rfcclub/loomkit/blob/master/HARNESS.md)
for how this fits with loomkit, hammerhead-debug, and pilotfish.
